# Diretrizes de Contribuição

Obrigado pelo interesse em contribuir com o desenvolvimento deste portfólio!

## Como Contribuir

1. **Fork o repositório**
2. **Crie uma branch descritiva para sua feature ou correção:**
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. **Mantenha os padrões de código:**
   - HTML5 semântico e acessível (com atributos ARIA adequados).
   - CSS3 moderno utilizando as variáveis de tema definidas em `:root` e `[data-theme="light"]`.
   - JavaScript puro (Vanilla JS), mantendo funções puras e alta performance sem bibliotecas externas desnecessárias.
4. **Commits Semânticos (Conventional Commits):**
   - `feat:` Novas funcionalidades ou componentes.
   - `fix:` Correções de bugs ou estilos.
   - `style:` Ajustes visuais, espaçamentos ou cores.
   - `docs:` Modificações na documentação.
   - `perf:` Otimizações de desempenho e Core Web Vitals.
   - `a11y:` Melhorias de acessibilidade.
5. **Envie um Pull Request:** Descreva com clareza as alterações realizadas.
