## ✨ Destaques de Design & Arquitetura Frontend

- 🌓 **Dual Theme Engine (Dark & Light Mode):** Alternância instantânea com transição suave, persistência inteligente em `localStorage` e suporte nativo ao `prefers-color-scheme`.
- 💎 **Glassmorphism Navbar:** Menu de navegação fixo com efeito de vidro fosco (`backdrop-filter: blur`), borda translúcida e indicador de link ativo ao rolar.
- ⚡ **Performance Nativa:** 100% construído com **HTML5 Semântico**, **CSS3 Moderno** (Variáveis CSS, Flexbox, CSS Grid) e **Vanilla JavaScript** puro (zero dependências pesadas, carregamento ultrarrápido).
- 📜 **Scroll Reveal Interativo:** Animações fluidas de aparição escalonada acionadas por `IntersectionObserver` de alta performance mantendo 60 FPS.
- ⌨️ **Dynamic Typing Hero:** Efeito de máquina de escrever digital apresentando as áreas de especialização.
- 📱 **Mobile-First & Totalmente Responsivo:** Experiência consistente e refinada em smartphones, tablets, laptops e monitores ultrawide.
- ♿ **Acessibilidade & Boas Práticas:** Respeito à preferência de redução de movimento (`prefers-reduced-motion`), tags ARIA, contraste cromático WCAG e hierarquia semântica correta.

## 🚀 Como Executar Localmente

### Opção 1: Abrir diretamente no navegador
Basta dar dois cliques no arquivo `index.html` na pasta do projeto.

### Opção 2: Com Live Server (VS Code)
1. Abra a pasta `portfolio` no Visual Studio Code.
2. Clique com botão direito em `index.html` e selecione **"Open with Live Server"**.

### Opção 3: Usando Python
```bash
# Na raiz da pasta do projeto:
python -m http.server 3000
```
Acesse `http://localhost:3000` no seu navegador.

## 🌐 Publicação no GitHub Pages

Este repositório está pronto para deploy automático! Para ativar:
1. Acesse o repositório em [github.com/Bergamin1234/portfolio](https://github.com/Bergamin1234/portfolio).
2. Vá em **Settings** > **Pages**.
3. Em **Build and deployment** > **Source**, selecione **Deploy from a branch** (ou **GitHub Actions**).
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**. Em instantes seu portfólio estará online no endereço:
   `https://Bergamin1234.github.io/portfolio/`
